GitHub access

Only someone with a token for this repository can upload. The token stays in this browser and is never added to the site.

How to make a token
  1. Open GitHub's new fine-grained token page.
  2. Under Repository access, choose Only select repositories and pick CA-Final-Suggested-Answers.
  3. Under Permissions, set Contents to Read and write. Nothing else is needed.
  4. Generate it, copy it, and paste it above.
